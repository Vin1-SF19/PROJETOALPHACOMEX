## 🎯 Overview

Panel Alpha is an **enterprise-grade operational system** built to centralize the daily work of an entire company in a single secure interface. It covers operations, CRM, fiscal compliance, real-time chat, HR, training, content automation and AI-assisted workflows.

The system is engineered around three core principles:

- **🔒 Security by design** — every server action validates auth, ownership and input
- **⚡ Real-time everywhere** — Pusher-driven notifications, chat, presence
- **🤖 AI-augmented** — embedded assistant (Bibble) + agent-driven development workflow

Built and maintained with help from a **squad of 20+ specialized AI agents** orchestrated through a master agent ("Bibble"). See `docs/AGENTS.md` for details.

## 🏗️ Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                        Panel Alpha (Web)                        │
│              Next.js 16 App Router + React 19                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   📱 UI Layer  →  shadcn/ui + Radix + Tailwind v4 + Framer      │
│   🔧 Logic     →  Server Components + Server Actions (Zod)      │
│   🔐 Auth      →  Auth.js v5 (JWT strategy)                     │
│   📡 Real-time →  Pusher channels (per-entity, role-gated)      │
│   💾 Data      →  Prisma + Turso (edge SQLite)                  │
│   ☁️ Storage    →  Vercel Blob (chat) + UploadThing (files)     │
│   🤖 AI         →  Claude API (Anthropic) — streaming + tools   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
                         ↑                        ↓
                  ┌──────────────┐       ┌──────────────────┐
                  │  AgentsBrain │       │  AlphaInstagram  │
                  │  (visualizer)│       │  (Electron app)  │
                  │              │       │  Puppeteer + IA  │
                  └──────────────┘       └──────────────────┘
```

### Permission Model

Sector-based with overrides:

```typescript
permissoesEfetivas(user) = setorPermissoes(user.setor)
                         ∪ overrides.add
                         - overrides.remove
```

3 base roles (`user`, `admin`, `ceo`) + sector inheritance + per-user overrides.

### Real-time Channels

```
private-admin-chamados      → new tickets (Admin/CEO only)
chat-{chamadoId}            → per-ticket chat
user-presence-{userId}      → online indicator
```

### Integration Points (Critical)

Every new module must register in **3 separate arrays** (no auto-sync):

| File | Array | Purpose |
|------|-------|---------|
| `src/components/PainelAlphaClient.tsx` | `modulos` | Main menu |
| `src/components/FormCadastro.tsx` | permissions | Admin grants access |
| `src/app/PainelAlpha/InfosPerfil/Atalhos/page.tsx` | `MODULOS_BASE` | Pinnable shortcuts |

## 🚀 Getting Started

### Prerequisites

- **Node.js** 20+ (LTS recommended)
- **npm** 10+ (or pnpm/yarn equivalent)
- **Turso CLI** (for production database) — [install guide](https://docs.turso.tech/cli)
- **Git**

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-org>/PanelAlpha.git
cd PanelAlpha

# Install dependencies
npm install

# Rebuild native bindings (LibSQL)
npm rebuild libsql

# Set up environment variables
cp .env.example .env.local
# Edit .env.local with your credentials

# Generate Prisma client + push schema
npx prisma generate
npx prisma db push

# Start dev server
npm run dev
```

App will be available at `http://localhost:3000`.

### Environment Variables

```bash
# Database (Turso)
TURSO_DATABASE_URL=libsql://your-db.turso.io
TURSO_AUTH_TOKEN=...

# Auth.js v5
AUTH_SECRET=...                       # openssl rand -base64 32
AUTH_URL=http://localhost:3000

# Pusher (real-time)
PUSHER_APP_ID=...
PUSHER_KEY=...
PUSHER_SECRET=...
PUSHER_CLUSTER=...
NEXT_PUBLIC_PUSHER_KEY=...
NEXT_PUBLIC_PUSHER_CLUSTER=...

# Upload
BLOB_READ_WRITE_TOKEN=...
UPLOADTHING_TOKEN=...

# Email
RESEND_API_KEY=...

# AI Integrations
ANTHROPIC_API_KEY=...
OPENAI_API_KEY=...

# OCR
AWS_ACCESS_KEY_ID=...
AWS_SECRET_ACCESS_KEY=...
AWS_REGION=us-east-1

# WhatsApp Notifications
CALLMEBOT_PHONE=...
CALLMEBOT_API_KEY=...
```

## 🔐 Security Principles

| Principle | Implementation |
|-----------|----------------|
| **Authenticate everywhere** | `auth()` in every server action and route handler |
| **Validate everything** | Zod schemas on all inputs |
| **Verify ownership** | `WHERE userId = session.user.id` in every user-scoped query |
| **Sanitize uploads** | Magic byte verification + size limits |
| **Rate limit** | Sensitive endpoints (auth, AI calls, uploads) |
| **No secrets in code** | All credentials via `.env.local` |
| **Headers** | CSP, HSTS, X-Frame-Options configured |
| **Logs** | Never log PII (CPF, salaries, tokens) |

## 🤝 Contributing

This is a **private repository**. Internal contributions follow this workflow:

1. Create feature branch from `main`
2. Implement following the **agent flow**: Scout → Echo/Nova → Forge → Anubis → Lens → Probe
3. Run all checks: `npm run lint && npx tsc --noEmit && npm run build`
4. Open PR with clear description and checklist
5. Code review required before merge

**Never bypass:**
- Authentication checks
- Zod validation
- Sector permission verification
- The 3 integration points (menu, permissions, shortcuts)
- Active theme system
